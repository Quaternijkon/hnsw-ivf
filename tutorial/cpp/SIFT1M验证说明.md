# SIFT1M 数据集验证自动聚类维护功能

## 概述

`2-IVFFlat-SIFT1M.cpp` 是基于 SIFT1M 数据集验证 IndexIVF 自动聚类维护功能的示例程序。该程序演示了在真实数据集上使用自动聚类维护功能的效果。

## SIFT1M 数据集

SIFT1M 是一个标准的向量检索基准数据集：

- **训练集**: 100,000 个向量 (sift_learn.fvecs)
- **数据库**: 1,000,000 个向量 (sift_base.fvecs)
- **查询集**: 10,000 个向量 (sift_query.fvecs)
- **Groundtruth**: 每个查询的最近邻 (sift_groundtruth.ivecs)
- **向量维度**: 128

### 下载数据集

1. 访问 http://corpus-texmex.irisa.fr/
2. 下载 **ANN_SIFT1M** 数据集
3. 解压到项目目录下的 `sift1M` 文件夹

数据集目录结构应该是：
```
sift1M/
├── sift_learn.fvecs      # 训练集
├── sift_base.fvecs       # 数据库
├── sift_query.fvecs      # 查询集
└── sift_groundtruth.ivecs # Groundtruth
```

## 程序功能

程序会执行以下操作：

1. **加载数据集**
   - 加载训练集、数据库、查询集和 groundtruth

2. **创建和训练索引**
   - 创建 IVF-Flat 索引（nlist=4096）
   - 使用训练集训练索引
   - 启用 direct_map (Hashtable)

3. **初始添加数据**
   - 添加 1,000,000 个数据库向量
   - 自动维护被插入的聚类

4. **初始搜索和评估**
   - 在 10,000 个查询上搜索
   - 计算 Recall@1, Recall@10, Recall@100

5. **插入操作**
   - 插入 10,000 个新向量（1% 的数据）
   - 自动维护被插入的聚类
   - 记录插入时间

6. **更新操作**
   - 更新 10,000 个向量（1% 的数据）
   - 自动维护被操作的聚类
   - 记录更新时间

7. **删除操作**
   - 删除 10,000 个向量（1% 的数据）
   - 自动维护被删除向量所在的聚类
   - 记录删除时间

8. **显示聚类统计信息**
   - 总向量数、聚类数量
   - 平均/最大/最小聚类大小
   - 空聚类数量

9. **最终搜索和评估**
   - 再次搜索并计算 Recall
   - 对比初始和最终的 Recall 值
   - 验证索引质量是否保持稳定

## 验证要点

1. **自动维护功能**

   - ✓ 删除操作后自动维护被删除向量所在的聚类

2. **索引质量**

   - ✓ 自动分裂大聚类
   - ✓ 自动合并小聚类

程序会记录以下性能指标：

- **插入时间**: 插入操作耗时
- **更新时间**: 更新操作耗时
- **删除时间**: 删除操作耗时
- **搜索时间**: 每次搜索的耗时

## 注意事项

1. **内存需求**: SIFT1M 数据集较大，需要足够的内存（约 500MB+）
2. **运行时间**: 完整运行可能需要几分钟到十几分钟，取决于硬件性能
3. **数据集路径**: 确保数据集路径正确，或使用命令行参数指定
4. **库路径**: 如果使用动态库，确保设置了 `LD_LIBRARY_PATH`

## 故障排除

### 1. 找不到数据集文件

```
错误: 未找到 SIFT1M 数据集目录: sift1M
```

**解决方案**: 
- 下载并解压 SIFT1M 数据集到 `sift1M` 目录
- 或使用命令行参数指定数据集路径

### 2. 找不到库文件

```
警告: 未找到编译后的 faiss 库文件！
```

**解决方案**: 
- 运行 `./重新编译faiss.sh` 重新编译 faiss 库

### 3. 内存不足

如果程序因内存不足而崩溃，可以：
- 减少插入/更新/删除的向量数量（修改代码中的 `n_insert`, `n_update`, `n_delete`）
- 使用更少的线程数（修改 `OMP_NUM_THREADS`）
