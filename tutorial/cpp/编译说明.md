# 重新编译 Faiss 库说明

由于修改了 faiss 源代码（`IndexIVF.h` 和 `IndexIVF.cpp`），需要重新编译 faiss 库才能使用新功能。


## 手动编译步骤

### 1. 进入项目根目录

```bash
cd /home/gpu/.cursor/worktrees/faiss__SSH__gpu_/LtbgC
```

### 2. 配置 CMake

```bash
# 创建 build 目录
mkdir -p build
cd build

# 配置 CMake（CPU 版本）
cmake .. \
    -DCMAKE_BUILD_TYPE=Release \
    -DBUILD_SHARED_LIBS=ON \
    -DBUILD_TESTING=OFF \
    -DFAISS_ENABLE_GPU=OFF \
    -DFAISS_ENABLE_PYTHON=OFF \
    -DFAISS_OPT_LEVEL=avx2 \
    -DCMAKE_INSTALL_PREFIX=./install
```

**如果需要 GPU 支持：**

```bash
cmake .. \
    -DCMAKE_BUILD_TYPE=Release \
    -DBUILD_SHARED_LIBS=ON \
    -DBUILD_TESTING=OFF \
    -DFAISS_ENABLE_GPU=ON \
    -DFAISS_ENABLE_PYTHON=OFF \
    -DFAISS_OPT_LEVEL=avx2 \
    -DCMAKE_CUDA_ARCHITECTURES="75;80" \
    -DCMAKE_INSTALL_PREFIX=./install
```

### 3. 编译库

```bash
# 编译基础版本
make -j$(nproc) faiss

# 编译 AVX2 优化版本（推荐）
make -j$(nproc) faiss_avx2

# 如果 CPU 支持 AVX512，可以编译优化版本
# make -j$(nproc) faiss_avx512
```

### 4. 验证编译结果

```bash
# 检查库文件是否生成
ls -lh build/lib/libfaiss*

# 应该看到类似输出：
# libfaiss.a
# libfaiss.so
# libfaiss_avx2.so
```

## 编译选项说明

### 基本选项

- `-DCMAKE_BUILD_TYPE=Release`: 启用优化编译
- `-DBUILD_SHARED_LIBS=ON`: 构建动态库（.so），便于链接
- `-DBUILD_TESTING=OFF`: 不构建测试（加快编译速度）
- `-DFAISS_ENABLE_GPU=OFF`: 禁用 GPU 支持（CPU 版本）
- `-DFAISS_ENABLE_PYTHON=OFF`: 禁用 Python 绑定（如果只用 C++）

### 优化选项

- `-DFAISS_OPT_LEVEL=avx2`: 启用 AVX2 优化（大多数现代 CPU 支持）
- `-DFAISS_OPT_LEVEL=avx512`: 启用 AVX512 优化（需要支持的 CPU）
- `-DFAISS_OPT_LEVEL=generic`: 通用优化（兼容性最好）

### GPU 选项（如果启用 GPU）

- `-DFAISS_ENABLE_GPU=ON`: 启用 GPU 支持
- `-DCMAKE_CUDA_ARCHITECTURES="75;80"`: 指定 GPU 架构
  - 75: Turing (RTX 20xx)
  - 80: Ampere (RTX 30xx, A100)
  - 86: Ada Lovelace (RTX 40xx)
  - 90: Hopper (H100)

## 编译示例程序

编译完成后，编译示例程序：

```bash
cd tutorial/cpp

# 编译示例程序
g++ -o 2-IVFFlat 2-IVFFlat.cpp \
    -I../../ \
    -L../../build/lib -lfaiss \
    -fopenmp -O3

# 或者使用 AVX2 优化版本
g++ -o 2-IVFFlat 2-IVFFlat.cpp \
    -I../../ \
    -L../../build/lib -lfaiss_avx2 \
    -fopenmp -O3 -mavx2
```

## 运行时设置库路径

如果使用动态库，需要设置 `LD_LIBRARY_PATH`：

```bash
export LD_LIBRARY_PATH=../../build/lib:$LD_LIBRARY_PATH
./2-IVFFlat
```

或者使用提供的运行脚本：

```bash
./run_2-IVFFlat.sh
```

## 常见问题

### 1. CMake 找不到依赖

如果 CMake 报错找不到某些依赖（如 BLAS），可以：

```bash
# 使用系统 BLAS
cmake .. -DBLA_VENDOR=Generic

# 或指定 Intel MKL 路径
cmake .. -DBLA_VENDOR=Intel10_64_dyn -DMKL_LIBRARIES=/path/to/mkl/libs
```

### 2. 编译时间过长

可以限制并行编译线程数：

```bash
make -j4 faiss  # 使用 4 个线程
```

### 3. 内存不足

如果编译时内存不足，减少并行线程数或关闭某些优化选项。

### 4. 链接错误

确保：
- 库路径正确：`-L../../build/lib`
- 库名称正确：`-lfaiss` 或 `-lfaiss_avx2`
- 设置了 `LD_LIBRARY_PATH`（使用动态库时）
